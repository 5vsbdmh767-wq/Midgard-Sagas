The year in Midgard has 12 months of 30 days. Six festival days fall between the months and don't belong to any of them, so the full year is 366 days. The new year starts with the first signs of spring, in Springmelt.

In the south, where it rarely snows, the winter months go by different names, shown in brackets below.

| Season | Month | Festivals |
| --- | --- | --- |
| Spring | Springmelt | New Year's Dawn, Mustering |
| | Sowing | |
| | Thunders | Rites of Spring |
| Summer | Goldflower | Crown Festival |
| | Low Summer | |

| | Last Leaf | Ghost Night |
| Winter | Rimetrail [First Fogs] | |
| | Snowfall [Winterwind] | Lantern Festival |

##### Days of the Week
Almost everyone in Midgard uses the same seven day names, from the [[Northlands]] to the Middle Sea. The elves and the [[The Mharoti Empire|Mharoti]] use their own.

| Volsday | Elothsday | Nazartesi |
