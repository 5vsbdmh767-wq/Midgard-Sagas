Tracking and incorporating weather in the game can create a more immersive experience for the players, especially in campaigns that heavily feature travel and exploration. Extreme weather can dramatically increase the difficulty of wilderness encounters, especially if weather conditions are severe enough to trigger hazards.

When your PCs first enter a new region, roll on the Temperature, Wind, and Precipitation tables to determine the immediate weather conditions for the area or choose something appropriate. Then roll 1d20 and consult the Weather Changes table to determine how the weather will change over time. Typically, rolling once per day is enough. However, at your discretion, more unstable areas or unique conditions might demand more frequent rolls.

###### Temperature                                                                                                   

| Stage (d6) |  Conditions  |
| :--------: | :----------: |
|     1      | Extreme Heat |
|     2      |     Hot      |
|     3      |     Warm     |
|     4      |     Cool     |
|     5      |     Cold     |
|     6      | Extreme Cold |
###### Wind

| Stage (d4) | Conditions    |
| ---------- | ------------- |
| 1          | Calm          |
| 2          | Moderate Wind |
| 3          | Strong Wind   |
| 4          | Gale Winds    |
###### Precipitation

| Stage (d4) | Conditions               |
| ---------- | ------------------------ |
| 1          | Clear                    |
| 2          | Fog/Overcast             |
| 3          | Hail/Rain/Snow           |
| 4          | Torrential Precipitation |
###### Weather Changes

| d20   | Temperature                             |
| ----- | --------------------------------------- |
| 1-14  | Remains Seasonal/One Stage More Typical |
| 15-17 | One Stage Colder                        |
| 18-20 | One Stage Warmer                        |

| d20   | Wind                                  |
| ----- | ------------------------------------- |
| 1-12  | Stays Seasonal/One Stage More Typical |
| 13-17 | One Stage Windier                     |
| 18-20 | Two Stages Windier                    |

| d20   | Precipitation                         |
| ----- | ------------------------------------- |
| 1-12  | Remains Season/One Stage More Typical |
| 13-17 | One Stage Increased Precipitation     |
| 18-20 | Two Stages Increased Precipitation    |
